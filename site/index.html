Fastcord GitHub

Chat, native.

A fast client for Discord, written from scratch. No browser inside — just a native renderer that starts instantly, scrolls smoothly, and idles at zero CPU.

macOS Apple silicon & Intel Windows 10 & 11, x64 Linux x86_64, any distro

Instant

Native GPU rendering (Metal, Direct3D 11, OpenGL) with an immediate-mode UI. Every interaction lands on the next frame.

Light on battery

Nothing renders unless something changes. Idle is zero frames, zero wakeups.

Small

One ~5 MB app. No Chromium, no Node, no bundled browser.

Familiar

Servers, channels, DMs, friends, reactions, emoji, GIFs, stickers and the layout you already know.

Voice

Voice chat with Discord's end-to-end encryption, written from the ground up.

Well-behaved

Sends the same requests as the official desktop client, at the same moments. See below.

Only shapes are shown, never values: method and path with ids folded, header names in the order they left the machine (from Chrome's and Fastcord's network logs), JSON field names, gateway opcodes, telemetry event names and property names. Indistinguishable on the wire

To Discord's servers, Fastcord behaves like the official desktop app: the same requests with Chrome's headers in Chrome's wire order, the same TLS and HTTP/2 handshakes, the same gateway messages and telemetry batches, sent at the same moments. Windows: unzip and run Fastcord.exe. It isn't code-signed yet, so SmartScreen may warn the first time: click More info → Run anyway.

Linux: extract the archive and run ./fastcord, or ./install.sh to add it to your app menu. One build for every distribution (glibc 2.17 or newer), on X11 and Wayland desktops.

First launch on macOS: Fastcord isn't notarized by Apple yet, so macOS blocks it the first time. Click Done, then open System Settings → Privacy & Security and click Open Anyway. After that it opens normally and shows an Update button when a new release is out.

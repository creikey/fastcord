Fastcord GitHub

Discord, native.

A fast Discord client written from scratch. No browser inside — just a native renderer that starts instantly, scrolls smoothly, and idles at zero CPU.

Download for macOS Apple silicon & Intel Windows coming soon Linux coming soon

Instant

Native Metal rendering with an immediate-mode UI. Every interaction lands on the next frame.

Light on battery

Nothing renders unless something changes. Idle is zero frames, zero wakeups.

Small

One ~5 MB app. No Chromium, no Node, no bundled browser.

Familiar

Servers, channels, DMs, friends, reactions, emoji, GIFs, stickers and the layout you already know.

Voice

Voice chat with Discord's end-to-end encryption, written from the ground up.

Well-behaved

Sends the same requests as the official desktop client, at the same moments. See below.

Indistinguishable on the wire

To Discord's servers, Fastcord looks like the official desktop app: the same requests, gateway messages and telemetry, in the same order, at the same moments. Each scenario was recorded from both clients and lined up request by request.

First launch on macOS: Fastcord isn't notarized by Apple yet, so macOS blocks it the first time. Click Done, then open System Settings → Privacy & Security and click Open Anyway. After that it opens normally and shows an Update button when a new release is out.

Encrypted DMs

For private conversations, use Signal. When both people use Fastcord, a DM can also be end-to-end encrypted with Signal's published protocols: Discord relays it but can't read it.

PQXDHSignal's post-quantum key agreement, with X25519 and ML-KEM-768.
Double RatchetA new key for every message, with ChaCha20-Poly1305.
Safety numbersCompare 60 digits to confirm who you're talking to.

One-on-one and group DMs: text, files, replies, edits, deletes and reactions. Discord still sees who you message and when, and roughly how large each message and file is. Prekeys are signed with SLH-DSA. The Triple Ratchet comes next; federated routing between self-hosted servers is in progress.

Host a server

Fastcord can run its own server: one file on your machine, with text, voice and video channels, Go Live, threads, files, emoji, events, roles and moderation. No Discord, no account; members join with their Fastcord key.

Start itRun the app with -serve:myserver.db: ./fastcord on Linux, Fastcord.app/Contents/MacOS/Fastcord on macOS, Fastcord.exe on Windows. It makes the file on first run and prints an invite.
Open the portTCP 4433 (-port:N for another). Allow it when Windows Firewall asks, and forward it on your router for friends outside your network.
Share the inviteThe fc:// link goes in Add a Server → Join a Server, with your public address in place of localhost. To own it, start it with -owner:<key> (fastcord -key prints yours), or join first with the one-use owner invite.

Voice and video use UDP on the same port. The owner manages storage, files, limits and backups from Server Settings. It keeps daily backups, and -install runs it as a service. Ctrl-C stops it; to update, start the new release on the same file. Whoever runs a server can read its channels, but not its encrypted DMs.

⚠ Not audited yet. The server hasn't had a security audit, so it may have vulnerabilities. One is coming soon.

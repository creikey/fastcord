# divider stays. Losing focus with the channel read then makes the marker stale, so the next message
# that stays unread moves the divider to itself and the bar counts just it, as the official
# ReadStateStore does (oldestUnreadMessageIdStale). Offline there is no client to ack, so "acked"
# stands in for the at-bottom ack.
